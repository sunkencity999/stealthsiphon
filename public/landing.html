MCP server · REST API · CLI · Web UI

The web, made readable for your agents.

Stealth Siphon gives an AI agent clean, compact Markdown instead of raw HTML. It also renders JavaScript apps in a real browser, extracts structured data, crawls within the limits you set, drives logins and forms, and watches pages for changes. Everything runs on your machine, with LM Studio or Ollama for local-model extraction.

Why

Agents are bad at the raw web. This fixes that.

Give an agent a plain HTTP fetch and it burns its context on markup, sees empty JavaScript shells, and gets stuck at the first login page. A malicious page can even trick it into requesting internal addresses. Stealth Siphon sits between your agent and the web.

Context is precious

Navigation, scripts, styles and tracking can be over 90% of a page. You get the main content as Markdown, in chunks the agent can page through, and the agent decides what to read next.

Modern sites need JavaScript

Auto mode spots empty single-page-app shells and bot walls (403/429/503) and switches to a real headless Chrome. No flags needed.

Real tasks are interactive

Logins, search boxes, "load more", infinite scroll. Persistent browser sessions return a compact snapshot, and the agent clicks [e12] instead of guessing selectors.

Agents want data, not prose

Get JSON from CSS selectors, or have your local model fill in a JSON Schema. Product lists, prices, people, events.

"Tell me when it changes"

Watches re-check on a schedule and store unified diffs. Later, the agent asks what changed. Webhooks are optional.

Pages can attack agents

Private, local and cloud-metadata addresses are blocked at every layer. Web content is clearly marked as untrusted, and robots.txt is respected by default.

Features

One local service, the whole toolkit

Clean Markdown

Readability-based main-content extraction with tables, absolute links, metadata (OpenGraph, JSON-LD) and a link inventory. Output is paged with maxChars/offset.

Auto rendering

Plain HTTP when it's enough, headless Chrome when the page needs it. Uses the Chrome you already have, so there's no browser download.

Structured extraction

CSS fields and repeated-item lists ("a.title@href"), or JSON Schema extraction by a local model.

Local LLMs

LM Studio, Ollama, or any OpenAI-compatible server. Auto-detects what's running and uses the loaded model.

Bounded crawling

Concurrent and rate-limited, with page and depth limits, include/exclude globs and sitemap seeding. Returns summaries first, full pages on demand.

Browser sessions

Navigate, click, type, select, scroll, wait, read, screenshot and evaluate, in isolated sessions that close when idle.

Change monitoring

Cron or presets like hourly, with SQLite run history, unified diffs and webhooks on change.

Safe by default

SSRF protection, loopback binding, Host/Origin guards, optional API key, robots.txt, and per-host rate limits.

Four ways to use it

For Claude Code, Claude Desktop, LocalClaw and any MCP client. It runs over stdio, or over Streamable HTTP at /mcp.

claude mcp add stealthsiphon -- node /path/to/stealthsiphon/bin/mcp.js

Every endpoint returns JSON, and errors carry stable codes.

curl -s localhost:4200/api/fetch -H 'content-type: application/json' \
  -d '{"url":"https://example.com","format":"markdown","maxChars":4000}'

Good for shell-based agents and scripts.

node bin/siphon.js fetch https://example.com
node bin/siphon.js extract https://quotes.toscrape.com --list .quote \
  --fields '{"text":".text","author":".author"}'
node bin/siphon.js crawl https://docs.example.com --max-pages 30 --include "/docs/**"

Point-and-click scraping, exports (JSON, CSV, TXT, HTML, SQLite, MongoDB, MySQL), and a scheduler for recurring tasks.

Tutorial

Connect it to your agent in five minutes

You need Node.js 18.17+ and Google Chrome (Chromium, Edge or Brave also work). LM Studio or Ollama is optional.

  1. Install

    git clone https://github.com/sunkencity999/stealthsiphon.git
cd stealthsiphon
npm install

  2. Register the MCP server

    Claude Code: stdio is simplest, and no server needs to be running:

    claude mcp add stealthsiphon -- node "$(pwd)/bin/mcp.js"

    Or run npm start and connect over HTTP. This also keeps scheduled watches running while no agent is open:

    claude mcp add --transport http stealthsiphon http://127.0.0.1:4200/mcp

    Claude Desktop, LocalClaw or any MCP JSON config:

    {
  "mcpServers": {
    "stealthsiphon": {
      "command": "node",
      "args": ["/absolute/path/to/stealthsiphon/bin/mcp.js"]
    }
  }
}

    In Claude Code, run /mcp. You should see stealthsiphon with 26 tools.

  3. Optional: turn on local-model extraction

    LM Studio: load a chat model, then start the server in the Developer tab. Stealth Siphon uses whatever model is loaded. Ollama: run ollama serve with a model pulled. Check what was found:

    node bin/siphon.js llm

  4. Just ask

    You don't need to name tools. The server tells your agent which tool fits which job.

    You sayThe agent uses
    "Summarize https://example.com/blog/post"fetch_page: article Markdown, ~20× fewer tokens
    "What does this React dashboard show?"fetch_page: auto-renders in Chrome
    "Every product and price on this sale page, as JSON"extract with a CSS list, or a schema filled in by your local model
    "Read the docs site and explain how auth works"crawl with include: ["/docs/**"], then get_crawl_page
    "Log in to staging with the test account and screenshot settings"browser_open, then browser_type, browser_click, browser_screenshot
    "Watch the vendor pricing page and tell me what changes"watch_page (daily), later get_changes

  5. Get the most out of it

    • Long pages: results say continue with offset=…. Page forward, or pass a selector to fetch just one section.
    • Listing and index pages: set mainContent: false. Article extraction can drop link lists.
    • Quiet watches: give watch_page a selector like #pricing so ads and timestamps don't count as changes.
    • robots.txt: disallowed paths return ROBOTS_DISALLOWED. Pass respectRobots: false only when you have permission.
    • Sharing on a network: set HOST=0.0.0.0 and STEALTHSIPHON_API_KEY.

Local LLMs

Your model, your machine

Schema extraction runs on a model you control. With LLM_PROVIDER=auto, Stealth Siphon finds whichever server is running and uses the model you already have loaded.

LM Studio

Start the server in the Developer tab. It uses the loaded model, with structured output via json_schema and an automatic fallback for models that reject it.

LMSTUDIO_URL=http://127.0.0.1:1234

Ollama

Run ollama serve. It uses OLLAMA_MODEL or the first installed chat model, constrained with Ollama's format schema.

OLLAMA_URL=http://127.0.0.1:11434

OpenAI-compatible

vLLM, llama.cpp server, LocalAI, or a hosted endpoint, with an optional API key.

OPENAI_COMPAT_URL=…

Built for reasoning models. The schema goes into the prompt as well as the decoding constraint, and <think> blocks are stripped before parsing. In testing, that took one extraction from 3,151 tokens with wrong values to 108 tokens with correct ones.

Security

Assume the agent is reading hostile pages

SSRF protection

Localhost, private ranges, link-local and cloud-metadata addresses are blocked. The check runs on the URL, after DNS, at socket connect, on every redirect, and on every request the browser makes.

Untrusted content markers

Web content comes back inside <untrusted_web_content> tags that pages can't close early.

Locked-down server

Binds to 127.0.0.1, rejects foreign Host headers and cross-origin requests, supports an optional API key, and never exposes stack traces or data files.

Polite by default

Respects robots.txt and Crawl-delay, with per-host concurrency and rate limits. You can override per request, with permission.
